# Olenna Oss Creative — Coming Soon homepage

Responsive one-page coming-soon homepage for `olennaosscreative.com`.

## Included
- Coming soon message for the embroidery kit store
- Contact email link: rather.fine.work@gmail.com
- Facebook, Instagram, YouTube, and Verra links
- Responsive desktop/mobile layout
- Custom floral embroidery hoop illustration (SVG)

## Publish updates
Upload and overwrite `index.html`, `styles.css`, `script.js`, and `README.md` in your GitHub repository, then commit the changes. If Cloudflare Pages is connected to the repository, it should automatically deploy the update.
